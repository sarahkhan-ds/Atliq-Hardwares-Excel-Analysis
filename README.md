# Atliq-Hardwares-Excel-Analysis
Sales and financial performance analysis using Microsoft Excel 


📌 Project Overview

This project focuses on analyzing the sales and financial performance of AtliQ Hardwares using Microsoft Excel. The objective is to transform raw data into meaningful business insights through customer analysis, market performance evaluation, and financial reporting.

🎯 Project Objectives

- Analyze customer-wise sales performance.
- Evaluate market performance against sales targets.
- Understand year-over-year (YoY) sales growth.
- Generate Profit and Loss (P&L) reports.
- Identify sales trends and performance gaps to support business decisions.

🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel formulas and functions
- Data Analysis and Reporting
- Conditional Formatting
- Year-over-Year (YoY) Analysis
- Profit and Loss (P&L) Analysis

📊 Key Analysis

- Customer Performance Report: Analyzed sales across customers and evaluated growth over time.
- Market Performance vs Target: Compared actual market performance against targets and identified performance gaps.
- Financial Analysis: Evaluated financial performance through Profit and Loss (P&L) reports.
- Sales Trend Analysis: Examined changes in sales performance between financial years.

💡 Key Learnings

- Improved practical Excel and data analysis skills.
- Learned to convert raw business data into structured reports.
- Developed an understanding of sales metrics and financial performance.
- Gained experience in presenting data to support business insights.
